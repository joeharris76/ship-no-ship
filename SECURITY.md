# Security policy

ship-no-ship decides whether pull requests may merge and runs AI reviewers
against untrusted pull request content, so security reports are welcome.

## Reporting a vulnerability

Report a suspected vulnerability privately through this repository's
"Report a vulnerability" form on the Security tab. Please do not open a public
issue or pull request for it.

Include what you found, how to reproduce it, and the impact you expect. You
will get an acknowledgement, and a fix or a decision, as soon as practical.

## Supported versions

Only the latest release receives security fixes.
